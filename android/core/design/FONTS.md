# Bundled fonts

The design system's faces (DESIGN.md §3), bundled as static instances under
`src/main/res/font/` so the app renders the same type offline.

| File prefix | Family | Copyright | License |
| --- | --- | --- | --- |
| `plus_jakarta_sans_*` | Plus Jakarta Sans (Latin brand face) | Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans) | SIL Open Font License 1.1 |
| `manrope_*` | Manrope (Cyrillic companion; Jakarta has no basic Cyrillic) | Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope) | SIL Open Font License 1.1 |
| `geist_mono_*` | Geist Mono (times, tabular figures) | Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font) | SIL Open Font License 1.1 |
