# Baseline profile for Planr's cold start, written by hand (there is no
# macrobenchmark module yet). profileinstaller installs it with the app, so
# ART compiles these classes ahead of time instead of interpreting them on
# the first launches. Compose, Room, Hilt and the other AndroidX libraries
# ship their own profiles; these rules cover Planr's code on the way to the
# first agenda frame:
#
#   PlanrApplication (Hilt graph, DataInitializer) -> MainActivity ->
#   PlanrTheme -> PlanrNavHost -> AgendaScreen / AgendaViewModel ->
#   OccurrenceRepository (Room + recurrence expansion) -> EventRepository.
#
# Syntax: H = hot, S = run at startup, P = run after startup; ** matches any
# path or name. Keep it to the startup path: every rule costs install time
# and disk.
